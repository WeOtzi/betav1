## Qué puede y qué no puede probar la preview

- **Puede probarse en modo demo:** navegación y apariencia visible, formularios/validaciones que el adaptador simule, estados y cambios locales con fixtures. Marcar resultados de comportamiento como `Simulado` cuando no sean persistencia remota.
- **No queda probado por un toast, endpoint HTTP ni esta inspección del inicio:** escritura persistente en Supabase, autorización/RLS, autenticación real, intercambio real cliente-artista, recepción de correos, enlaces de recuperación, Google/Instagram, soporte externo, archivos privados o cobros.
- **Requiere autorización de Isaí:** entorno y cuentas de prueba identificadas; dos cuentas/perfiles de navegador para intercambio; buzón de prueba para correo; servicio/configuración aprobados para integraciones y archivos. No ensayar contra usuarios ni datos reales.
